## Sobre este repositorio

Este repositorio contiene **8 proyectos prácticos** realizados durante mi aprendizaje de manipulación del DOM en freeCodeCamp. Cada proyecto demuestra diferentes técnicas y patrones para interactuar con el DOM de forma dinámica.

**Objetivo:** Crear un punto de referencia personal para consultar en el futuro y mostrar mi progreso en JavaScript.

## Proyectos incluidos

| # | Proyecto | Descripción | Conceptos clave |
|---|----------|-------------|-----------------|
| 00 | **Theory** | Base teórica del DOM | `document`, `window`, nodos |
| 01 | **Storytelling App** | Generador interactivo de historias | Template strings, eventos de formulario |
| 02 | **Emoji Reactor** | Reacciones con emojis dinámicos | Event listeners, innerHTML |
| 03 | **Icon** | Manipulación de iconos | Cambio de clases CSS, toggle |
| 04 | **Music Instrument Filter** | Filtro de instrumentos musicales | `filter()`, `map()`, select dinámico |
| 05 | **Real-time Character Counter** | Contador de caracteres en tiempo real | `input` event, `textContent` |
| 06 | **Lightbox Viewer** | Visor de imágenes con modal | Creación/eliminación de elementos, eventos de teclado |
| 07 | **RPS Game** | Piedra, papel o tijera | Lógica de juego, manipulación de resultados |
| 08 | **Football Team Cards** | Tarjetas de equipo de fútbol | Filtros, renderizado dinámico, objetos anidados |

## Tecnologías utilizadas
